# سامانه پردازش گفتار فارسی و شبیه‌سازی صدا

پاسخ سؤال دوم ارزیابی عملی هوش مصنوعی: یک سامانه با دو بخش
۱) **تبدیل گفتار فارسی به متن** برای فایل‌های ۳۰ تا ۶۰ ثانیه‌ای، همراه با سنجش WER/CER در برابر متن مرجع؛
۲) **تبدیل متن به گفتار با صدای گوینده** (Zero-shot voice cloning) از روی یک نمونه کوتاه صدا.

هر دو بخش در یک رابط وب ساده (Gradio، راست‌به‌چپ) در دسترس است و همه مدل‌ها به‌صورت محلی روی یک کارت گرافیک ۱۲ گیگابایتی اجرا می‌شوند؛ هیچ داده‌ای به سرویس بیرونی فرستاده نمی‌شود.

## معماری

```
                 ┌──────────── رابط Gradio (app.py) ────────────┐
 فایل صوتی ──►  │ ffmpeg → ۱۶ کیلوهرتز مونو → برش در مکث (≤۲۸ ث) │
                 │ → Whisper large-v3-turbo فارسی (fp16، batch)   │ ──► متن + WER/CER
                 │                                               │
 نمونه صدا ──►  │ XTTS-v2 (ParsVoice): بردار گوینده از نمونه     │
 متن جدید  ──►  │ متن → یکسان‌سازی حروف، عدد به حروف، جمله‌بندی   │ ──► صدای ۲۴ کیلوهرتز
                 │ → تولید جمله‌به‌جمله و اتصال با مکث کوتاه       │     + شباهت گوینده (ECAPA)
                 └───────────────────────────────────────────────┘
```

| بخش | مدل | دلیل انتخاب |
|---|---|---|
| گفتار به متن | [`MohammadGholizadeh/whisper-large-v3-turbo-persian`](https://huggingface.co/MohammadGholizadeh/whisper-large-v3-turbo-persian) (MIT) | Whisper turbo تنظیم‌شده روی حدود ۵۳۴ ساعت گفتار فارسی؛ طبق کارت مدل، آموزش‌دیده روی گفتار خوانده‌شده، یوتیوب و دیالوگ فیلم |
| مبنای مقایسه | [`openai/whisper-large-v3-turbo`](https://huggingface.co/openai/whisper-large-v3-turbo) | همان معماری بدون تنظیم فارسی، برای نشان‌دادن اثر تنظیم |
| شبیه‌سازی صدا | [`MohammadJRanjbar/ParsVoice-XTTS`](https://huggingface.co/MohammadJRanjbar/ParsVoice-XTTS) (مجوز: متن کارت CPML، سربرگ صفحه MIT؛ پیش از استفاده تجاری بررسی شود) | XTTS-v2 تنظیم‌شده روی پیکره ParsVoice (۲٬۲۰۰ ساعت، ۱٬۸۰۰+ گوینده فارسی)؛ شبیه‌سازی از چند ثانیه صدا |
| سنجش شباهت گوینده | [`speechbrain/spkrec-ecapa-voxceleb`](https://huggingface.co/speechbrain/spkrec-ecapa-voxceleb) | بردار گوینده ECAPA-TDNN؛ شباهت کسینوسی بین نمونه و خروجی |

## ساختار پروژه

```
app.py                  رابط کاربری (دو زبانه: گفتار→متن، متن→گفتار)
pv/audio.py             خواندن هر قالب صوتی با ffmpeg و ذخیره wav
pv/text.py              یکسان‌سازی متن فارسی برای امتیازدهی و برای TTS، عدد به حروف، جمله‌بندی
pv/stt.py               بخش گفتار به متن (برش در مکث + Whisper)
pv/tts.py               بخش شبیه‌سازی صدا (XTTS-v2 / ParsVoice)
pv/metrics.py           WER، CER، CER بدون فاصله، شباهت گوینده
scripts/prepare_samples.py  ساخت نمونه‌های آزمون از FLEURS فارسی
scripts/evaluate.py     ارزیابی کامل و نوشتن results/eval.json و results/eval.md
scripts/rescore.py      امتیازدهی دوباره متن‌های ذخیره‌شده با قواعد مختلف نیم‌فاصله
scripts/tune_clone.py   مقایسه تنظیمات شبیه‌سازی (results/tune.md)
scripts/diagnose_clones.py  بررسی کیفیت نمونه‌های مرجع و آنچه STT از خروجی می‌شنود
scripts/smoke_app.py    آزمون هر دو زبانه رابط از طریق API
samples/                نمونه‌های ورودی (stt_*.wav + متن مرجع، voice_*.wav)
results/                متن‌های استخراج‌شده، نتایج ارزیابی
results/clones_takes1/  صداهای تولیدی با تنظیمات نهایی
results/before_fixes/   چند صدای تولیدی پیش از اصلاحات، برای مقایسه شنیداری
REPORT.md               گزارش نهایی
```

## نصب و اجرا

نیازمندی‌ها: لینوکس و Python 3.12. آزمون‌ها روی RTX 3060 با ۱۲ گیگابایت حافظه و روی CPU با ۲۴ رشته انجام شده است. بیشینه حافظه GPU سنجیده‌شده: ۲٫۱۱ گیگابایت برای گفتار به متن و ۳٫۶۷ گیگابایت برای شبیه‌سازی.

```bash
python3.12 -m venv .venv
.venv/bin/pip install torch==2.8.0 torchaudio==2.8.0 --index-url https://download.pytorch.org/whl/cu128
.venv/bin/pip install -r requirements.txt

# مدل ParsVoice-XTTS دروازه‌دار است: در صفحه مدل شرایط را بپذیرید و توکن بسازید
.venv/bin/hf auth login   # پس از دانلود مدل، توکن دیگر لازم نیست

.venv/bin/python app.py                 # http://localhost:7860
.venv/bin/python app.py --share         # لینک عمومی موقت gradio.live
CUDA_VISIBLE_DEVICES= .venv/bin/python app.py   # اجرا فقط روی CPU
```

> **نکته نسخه‌ها:** coqui-tts روی PyTorch ≥ ۲٫۹ به torchcodec و کتابخانه‌های سیستمی FFmpeg نیاز دارد؛ برای اجرا بدون دسترسی مدیر سیستم، PyTorch 2.8 استفاده شده است.

### بازتولید ارزیابی

```bash
.venv/bin/python -m scripts.prepare_samples          # دانلود FLEURS fa (test) و ساخت نمونه‌ها
.venv/bin/python -m scripts.evaluate --stt-corpus 300 --tts
```

## نتایج

جزئیات کامل در [`results/eval.md`](results/eval.md) و [`REPORT.md`](REPORT.md).

**گفتار به متن** — ۳۰۰ جمله از بخش آزمون FLEURS فارسی (۷۸ دقیقه)، روی RTX 3060:

| مدل | WER | CER | CER بدون فاصله | ضریب زمان اجرا (RTF) |
|---|---|---|---|---|
| Whisper turbo فارسی | **۸٫۹٪** | ۲٫۸٪ | ۲٫۸٪ | ۰٫۰۴۴ (۲۳ برابر سریع‌تر از زمان واقعی) |
| Whisper turbo پایه | ۱۸٫۰٪ | ۵٫۴٪ | ۵٫۷٪ | ۰٫۰۴۴ |

روی سه فایل ۴۱ تا ۵۲ ثانیه‌ای، مدل فارسی WER ۲٫۸ تا ۷٫۶ درصد داشت و هر فایل را در کمتر از ۲ ثانیه پردازش کرد. حافظه GPU: ۲٫۱ گیگابایت.

**شبیه‌سازی صدا** — ۴ گوینده × ۳ پاراگراف، روی CPU با ۲۴ رشته:

| حالت | WER رفت‌وبرگشتی | CER رفت‌وبرگشتی | شباهت گوینده | RTF |
|---|---|---|---|---|
| پیش از اصلاحات (روی GPU) | ۳۹٫۵٪ | ۲۹٫۰٪ | ۰٫۶۵ | ۰٫۳۲ |
| **تنظیمات نهایی** | **۱۰٫۶٪** | **۳٫۴٪** | **۰٫۶۹** | ۱٫۰۷ |
| تنظیمات نهایی، فقط ۶ نمونه کنارگذاشته‌شده از تنظیم | ۱۳٫۶٪ | ۴٫۰٪ | ۰٫۷۰ | — |

CER رفت‌وبرگشتی یعنی صدای تولیدشده دوباره رونویسی و با متن ورودی مقایسه شود. این شاخص وضوح را می‌سنجد، نه طبیعی‌بودن را؛ طبیعی‌بودن باید با شنیدن فایل‌ها قضاوت شود. محدودیت‌ها در بخش ۶ گزارش آمده است.

## ملاحظات اخلاقی

شبیه‌سازی فقط پس از تأیید رضایت صاحب صدا (چک‌باکس اجباری در رابط) انجام می‌شود. نمونه‌های این مخزن از پیکره عمومی FLEURS (مجوز CC-BY 4.0) گرفته شده‌اند. متن کارت مدل ParsVoice-XTTS مجوز CPML را با محدودیت استفاده تجاری ذکر می‌کند، در حالی که سربرگ صفحه MIT را نشان می‌دهد.
